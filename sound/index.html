02  Waveform types

OscillatorNode.type sets the shape of the wave the oscillator outputs, which changes the tone you hear. Press Play on any card to listen.

mode

sine is the default value. An oscillator can also take a custom shape through setPeriodicWave(), which sets the type to custom.

Every sound here is synthesised live with the Web Audio API. There are no audio files.
