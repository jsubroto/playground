02  Reading the bits

The same pattern, decoded field by field. A float is a sign, a power of two and a significand multiplied together, and every value it can hold is an exact binary fraction.

Bits follow IEEE 754 binary32 and binary64, most significant bit first. Decimal input is rounded to the nearest float, ties to even, using exact BigInt arithmetic.
